# EPSI · Contactos

Página de contactos de EPSI, Espacio Psi Interdisciplinario, en City Bell y La Plata.

Sitio estático con HTML, CSS y JavaScript. No necesita instalación de dependencias ni compilación.

## Archivos

- `dist/index.html`: diseño y datos de las profesionales, en el arreglo `professionals`.
- `dist/logo-epsi.png`: ícono de trabajo en equipo proporcionado por el usuario, creado por Vectors Market (Flaticon), con atribución en el pie de página.
- `vercel.json`: publicación de la carpeta `dist` en Vercel.

## Vista local

Abrir `dist/index.html` en el navegador o ejecutar `python -m http.server 8000 --directory dist`.

## Vercel

Importar el repositorio de GitHub. Usar la raíz del repositorio como Root Directory y el preset Other. La carpeta de salida `dist` está declarada en `vercel.json`. No requiere comando de compilación.

Una vez conectado, los cambios enviados a la rama de producción se publican automáticamente.
